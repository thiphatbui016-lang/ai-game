## CLI 使用方式

在 train-h20 上执行：

```bash
export APP=/home/jovyan/apps/skin-tokens
export MODEL=/home/jovyan/code/src/skin-tokens.cpp/models/SkinTokens-GGUF/F16
export LD_LIBRARY_PATH="$APP/lib:$APP/bin:/home/jovyan/conda/envs/skintokens/lib:$LD_LIBRARY_PATH"
```

检查模型：

```bash
"$APP/bin/skintokens-cli" inspect "$MODEL" --device cpu
```

给没有骨骼的 GLB 自动生成骨骼和权重：

```bash
"$APP/bin/skintokens-cli" rig \
  "$MODEL" \
  /home/jovyan/input/character.glb \
  /home/jovyan/output/character-rigged.glb \
  --device cpu
```

给已有骨骼的 GLB 生成皮肤权重：

```bash
"$APP/bin/skintokens-cli" skin \
  "$MODEL" \
  /home/jovyan/input/character.glb \
  /home/jovyan/input/skeleton.glb \
  /home/jovyan/output/character-skinned.glb \
  --device cpu \
  --fit global
```

查看 GLB 信息：

```bash
"$APP/bin/skintokens-cli" glb-info \
  /home/jovyan/input/character.glb
```
