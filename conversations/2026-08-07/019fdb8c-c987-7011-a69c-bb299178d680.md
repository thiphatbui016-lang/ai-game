核心计算应当是：

```python
COORD_S = np.diag([1.0, -1.0, -1.0])

# estimator 已经对 joint_coords 翻过 Y/Z；
# pred_global_rots 没有翻，所以这里把所有位置恢复到原始 MHR 空间。
J_cm = (COORD_S @ J_estimator.T).T * 100.0
G = pred_global_rots

for name in BODY_NAMES:
    src = MHR_INDEX[name]
    parent_name = BODY_PARENT[name]

    if parent_name is None:
        root_position = J_cm[src]
        local_rotation[name] = G[src]
        offset[name] = np.zeros(3)
    else:
        parent_src = MHR_INDEX[parent_name]

        offset[name] = (
            G[parent_src].T
            @ (J_cm[src] - J_cm[parent_src])
        )

        local_rotation[name] = (
            G[parent_src].T
            @ G[src]
        )
```
