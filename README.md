# AI Game · 快速排序

这个仓库用来学习和提交算法练习。当前已实现 **快速排序（Quick Sort）**。

## 怎么运行

### 方法一：直接打开网页（推荐，不用安装任何软件）

用浏览器打开 `index.html` 即可：

1. 在输入框里填入数字，用逗号或空格隔开，例如：`8, 3, 9, 1, 5, 2`
2. 点击「开始排序」
3. 页面会逐步展示每一次划分（选基准、分左右、递归）

### 方法二：用 Python

如果电脑里已经有 Python 3，在项目目录执行：

```bash
python3 quicksort.py
```

## 算法思路（30 秒看懂）

1. 从数组里选一个数字当 **基准（pivot）**
2. 把比基准小的放到左边，比基准大的放到右边
3. 对左边、右边分别再做同样的事，直到每一段只剩 0 或 1 个数字

平均时间复杂度：O(n log n)  
最坏时间复杂度：O(n²)（例如已经有序时，若总选两端当基准）
